# Citation

If you use `dataexcept` in academic work, please cite it using the metadata in
the [`CITATION.cff`](https://github.com/DiogoRibeiro7/DataExcept/blob/main/CITATION.cff)
file at the root of the repository. It carries the author's ORCID, affiliation
and versioned release information.

GitHub renders that file into ready-made APA and BibTeX snippets — use the
**Cite this repository** button in the sidebar of the
[repository page](https://github.com/DiogoRibeiro7/DataExcept).
